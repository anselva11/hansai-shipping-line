# HANSAI SHIPPING LINE

Official corporate website for **HANSAI SHIPPING LINE** — Precision Maritime Logistics & Global Ocean Transport.

## 🚢 Overview
A modern, minimalist corporate web portal built with semantic HTML5, Tailwind CSS, Lucide icons, and Vanilla ES6+ JavaScript.

### Core Features:
- **Interactive Container Tracking Simulator**: Real-time simulation of maritime shipments (B/L, Booking, Container ID).
- **Global Freight Rate Estimator**: Dynamic ocean freight calculation by container size, cargo type, origin/destination ports, and reefer temperature controls.
- **Fleet & Operations Showcase**: Interactive vessel, container specifications, and terminal hub explorer.
- **Service & Logistics Directory**: Comprehensive portfolio covering FCL, LCL, Intermodal Rail & Drayage, Customs Brokerage, and Cold-Chain Logistics.
- **Responsive & High Performance**: Optimized assets, accessible color contrast, and seamless mobile experience.

## 🛠️ Tech Stack
- **HTML5 & Vanilla JavaScript (ES6+)**
- **Tailwind CSS**
- **Lucide Icons**
- **Google Fonts** (Outfit & Plus Jakarta Sans)

## 🚀 Running Locally
You can preview the site locally using any static web server:

```bash
# Using Node.js built-in server script
node server.js
```
Then open `http://localhost:3000` in your web browser.
